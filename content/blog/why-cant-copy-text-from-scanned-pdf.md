If you **can’t copy text from a scanned PDF**, the pages may contain pictures of text rather than selectable characters. A PDF viewer can display the page, but selecting or searching words requires a text layer. Optical character recognition (OCR) can create one, though results should be reviewed for errors. A PDF text extractor works when the document already contains selectable text.

## Scanned page or text-based PDF?

Try selecting a sentence and copying it into a plain-text editor. If no words are selected—or the copied result is empty—the page may be a scan. Some PDFs mix scanned pages and selectable text, so check more than one page. A scan is essentially an image inside a PDF, not automatically editable text.

If the PDF already contains selectable text, [extract it with our PDF to Word tool](/tools/pdf-to-word) and review the text-focused result.

## When to use OCR and when to extract text

Use OCR when a scanned page needs searchable or editable text. OCR software estimates characters from the image and can misread low-resolution scans, unusual fonts, or complex layouts. If text is already selectable, extraction can copy it without OCR. The resulting text-focused document may not preserve the original page design, tables, or images.

## Common questions about copying text from scanned PDFs

### How can I tell whether a PDF is scanned?

Open the document and try selecting a line of text, then copy it into a plain-text editor. If the page behaves like one picture or nothing meaningful is pasted, it may be scanned. Test several pages because one document can contain both scanned images and pages with selectable text.

### Does OCR make scanned PDF text perfectly accurate?

No. OCR recognizes likely characters from the page image, and its accuracy depends on scan clarity, page alignment, font, language, and layout. It may confuse similar characters or miss small text. Review the recognized text against the original before using it in a form, report, or other important document.

### Can the PDF to Word tool read a scanned document?

The tool extracts selectable text that is already present in a PDF; it does not convert page images into text with OCR. If you cannot select or copy words from a scanned page, run an OCR process first, save the resulting searchable PDF, and then check that the text layer is accurate.

### Will extracted text keep the PDF's formatting?

Text extraction focuses on words rather than reproducing the original page design. Paragraphs may flow differently, and columns, tables, images, headers, or spacing can change or be omitted. Review the Word-compatible document after downloading and make any layout changes you need before sharing or relying on it.
